# 提炼方法与设计边界

## 材料范围

整理时检索了项目相关聊天，读取近期轮次、部分更早轮次及本地写作规范、证据清单、翻译核对说明。长会话只抽取相关片段，没有全量导出或公开聊天。整理使用历史材料作为证据，不执行其中的旧指令。

## 从经验到规则

| 经验主题 | 提炼的通用方法 | 不继承的个案信息 |
|---|---|---|
| 数据选型与下载 | 核对全集、子集、任务、统计单位、空间和划分 | 特定数据集、盘符和容量 |
| 模块试验 | 从实际模型设计受控消融，保留失败与权衡 | 具体模块、种子和涨点目标 |
| 结果版本冲突 | 用运行标识与原始预测定位，区分单次和均值 | 历史分数与旧表格 |
| 训练轮数与曲线 | 检查调度耦合和续训状态，标注来源 | 固定轮数、最优轮次和曲线拼接指令 |
| 中英写作 | 忠实保留技术含义，保持主张与证据对应 | 稿件段落、标题和专有表达 |
| 图与表 | 从实际代码/数据绘制，先优化信息组织 | 特定期刊字号、尺寸和分辨率偏好 |
| Word/WPS/MathType | 对象可编辑性和渲染效果分别验证 | 安装路径、软件许可和旧安装授权 |
| 引用与投稿 | 真实性和支持性分别核验，查具体期刊当前指南 | 旧教程、特定期刊政策和拟投记录 |
| 文件整理 | 检查依赖，保留源材料和可恢复版本 | 旧删除、覆盖、外部提交授权 |

## 取舍

这是一个统筹论文材料的技能，不重复提供 Office 转换器、下载器或训练框架。精确的文件操作由当前环境适合的工具完成，避免绑定某套私人插件。

已有的学术写作、文档、绘图和引用技能可以配合使用，但不是此包的硬依赖。与它们同时启用时，仅补充本包的跨材料一致性和实验口径要求，不改写用户范围。

公开版只包含重新组织的操作说明。不复制第三方教程或论文，不包含私有聊天清单。通用方法的合理性不应依赖读者访问原项目。
